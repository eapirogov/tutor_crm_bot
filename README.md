# Tutor CRM — веб-CRM для репетитора

Небольшая CRM, которую я написал под себя, чтобы вести учеников, расписание и
оплаты в одном месте вместо заметок и таблиц. Рассчитана на одного пользователя,
поэтому без ORM и очередей — FastAPI, SQLite и серверный рендеринг Jinja2.

## Возможности

**Ученики**
- карточка: имя, имя родителя, контакт, предмет, ставка за занятие, заметки
- контакт автоматически становится кликабельным: `@username` → ссылка на
  Telegram, цифры → `tel:`
- архивирование вместо удаления — история занятий и оплат сохраняется

**Расписание**
- недельная сетка с перелистыванием недель
- статусы занятия: запланировано / проведено / отменено / не пришёл
- регулярные занятия: массовое создание по шаблону (например «пн, ср 17:00»)
- к каждому занятию — домашнее задание и заметка о прогрессе

**Оплаты и баланс**
- тарифы: разовое занятие и абонементы на 5 и 10 занятий
- покупка пакета добавляет занятия на баланс ученика (в штуках)
- баланс считается как купленные занятия минус проведённые
- доход по месяцам для сводки

**Надёжность**
- резервная копия базы при каждом запуске, хранятся последние 14

## Стек

| Слой | Технология |
|---|---|
| Веб-фреймворк | FastAPI |
| Сервер | uvicorn |
| Шаблоны | Jinja2 (серверный рендеринг) |
| База данных | SQLite (модуль `sqlite3`, без ORM) |
| Формы | python-multipart |

```

│   ├── student_detail.html     # карточка ученика
│   ├── schedule.html           # недельное расписание
│   └── money.html              # оплаты и доход по месяцам
└── static/style.css
```

## Схема БД

| Таблица | Назначение |
|---|---|
| `students` | ученики: контакты, предмет, ставка, заметки, флаг архива |
| `lessons` | занятия: время, статус, цена, домашка, заметка о прогрессе, шаблон повтора |
| `payments` | покупки пакетов: сумма, сколько занятий добавлено, тариф |

```
students ──┬── lessons   (student_id, dt, status, homework, progress_note)
           └── payments  (student_id, dt, amount, lessons_count, package)

баланс ученика = SUM(payments.lessons_count) − COUNT(проведённых занятий)
```

## Запуск

```bash
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
uvicorn app:app --reload
```

Открыть http://127.0.0.1:8000 — база и таблицы создаются при первом запуске.

Рабочая база (`tutor.db`) и её копии (`backups/`) в репозиторий не входят —
они в `.gitignore`, потому что содержат данные учеников.
